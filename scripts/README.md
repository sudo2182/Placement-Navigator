# Scripts

This folder contains utility scripts for the project.

## Scripts

- **seed_database.py** - Seed database with sample data
- **migrate_database.py** - Database migration utility
- **setup_postgresql.sh** - PostgreSQL setup script
- **start_services.sh** - Start backend and frontend services
- **run_tests.sh** - Run test suite
- **test_api_connectivity.py** - Test API connectivity and external services

## Usage

```bash
# Run from project root
python scripts/seed_database.py
bash scripts/start_services.sh
```
